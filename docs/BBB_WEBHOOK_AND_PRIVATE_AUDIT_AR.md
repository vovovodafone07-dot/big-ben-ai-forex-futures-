# ربط BBB وفحص الحالة وإثبات النقل

## ما ثبت وما لم يثبت
التنبيهات الثمانية المرصودة نشطة على مؤشر BBB Ref9.1 وفريم M15، وبها خطوط Entry وSL وTP واحد وRegular close. لا تُغيّر شروط المؤشر أو الفريم أو التنبيهات الأخرى. نسخ M5 القديمة المذكورة في تقارير سابقة ليست وصفاً للتنبيهات الثمانية المرصودة حالياً.

MCP يفحص التنبيهات لكنه لا يضيف Webhook؛ واجهته الحالية لا توفر تحقق العامل الثاني المطلوب. يجب إكمال تعديل الإشعارات على جلسة TradingView المصرح بها. اتصال MCP لا ينقل جلسة تسجيل الدخول إلى المتصفح السحابي.

## العنوان والقوالب
عنوان الاستقبال الموحد:
`https://bigben-ai-pro-rebound.onrender.com/v1/tradingview/bbb`

القوالب الثمانية في [BBB_WEBHOOK_TEMPLATES.json](examples/BBB_WEBHOOK_TEMPLATES.json). توضع قيمة `BIGBEN_BBB_WEBHOOK_TOKEN` المستقلة مكان النص الإرشادي، ولا توضع كلمات مرور الحسابات أو توكن Telegram في الرسالة أو الرابط.

| 6094195172 | CAPITALCOM:SPX500 | شراء |
| 6094194393 | SKILLING:US30 | بيع |

الحقول: المخطط ومعرف التنبيه والسر والرمز والاتجاه والفريم ووقت الإرسال ووقت افتتاح الشمعة والدخول والوقف والهدف والإغلاق. أسعار plots ترسل كنصوص رقمية ثم تتحقق المنصة من محدوديتها واتجاهها وحساب RR. تستخدم `timenow` للإرسال و`time` للشمعة. لا تقبل قيماً غير رقمية أو تنبيهاً أقدم من ثلاث دقائق أو شمعة M15 غير مغلقة. بصمة الحدث تشمل معرف التنبيه والرمز والاتجاه والشمعة.

الاستقبال يحفظ الحدث ويعيد الإقرار قبل التحليل. عامل استرجاع يلتقط أحداث BBB التي لم تستكمل بعد إعادة التشغيل. التنبيه القديم يبقى محفوظاً ولا يُعاد كصفقة حديثة. لا يوجد ضمان مطلق لوصول الشبكة أو زمن الاستجابة عند نوم Render المجاني. تراجع حالة التسليم في سجل TradingView، لا من نجاح رفع الكود وحده.

المصدر الرسمي: [إعداد Webhook لدى TradingView](https://www.tradingview.com/support/solutions/43000529348-how-to-configure-webhook-alerts/)؛ الطلب POST وJSON صحيح، ويلزم العامل الثاني، والاستقبال محدود زمنياً بثلاث ثوان. لا تعطّل الحماية ولا تغيّر استراتيجية Pine.

## الأسعار والدقة وحالة السوق
| الأصل | مصدر الأسعار الخادمي المثبت | مرجع حجم الحركة |
|---|---|---|
| NQ / MNQ | غير متصل أو غير موثق حالياً | 0.25 نقطة؛ 5 / 0.50 دولار للحركة |
| ES / MES | غير متصل أو غير موثق حالياً | 0.25 نقطة؛ 12.50 / 1.25 دولار للحركة |
| GC / MGC | غير متصل أو غير موثق حالياً | 0.10 دولار للأونصة؛ 10 / 1 دولار للحركة |
| FOREXCOM:XAUUSD / CAPITALCOM:NAS100 | لقطة تنبيه فقط؛ لا تغذية OHLC مستمرة مثبتة | يلزم تحقق مواصفات مزود CFD نفسه |

Barchart مسار فحص قائم في المستودع، لكنه ليس مصدراً حياً مثبتاً بمجرد وجود مفتاح. Twelve Data المستخدم للفوركس ليس إثبات تغطية هذه العقود أو CFD المطابق. لا تستبدل عقد Futures بذهب فوري أو CFD، ولا تعتبر `1!` عقد انتهاء محدداً. `connected_symbols_v2.py` يتحقق من دقة العقد وبورصته، لكنه لا يخلق استحقاق بيانات.

المرجع: [CME Micro E-mini](https://www.cmegroup.com/articles/faqs/micro-e-mini-equity-index-futures-frequently-asked-questions.html) و[Micro Gold](https://www.cmegroup.com/education/lessons/micro-gold-and-micro-silver-futures-product-overview). يجب التحقق من تقويم جلسة العقد والعطل والصيانة ووقت البيانات، وليس جدولاً عاماً أو آخر سعر قديم فقط. عند غياب هذا الدليل تحجب المنصة إرسال الصفقة. لذلك ربط الأسعار الحية ما زال متطلباً خارجياً غير مكتمل، ولم يُشتر مصدر جديد.

## فحص الحالة الخاصة
`GET /v1/audit/state` يقبل فقط الرأس `X-BigBen-Audit-Token` بقيمة `BIGBEN_AUDIT_TOKEN` المستقلة. لا يفتح الواجهة العامة ولا يمنح وصولاً إلى بقية API ولا يصدّر كلمات المرور أو توكنات المزودين. يعرض نسخة الخادم والأصول وحالة الأسعار وأعداد الأحداث وإيصالات اختبار النقل.

شغّل `python scripts/check_private_state.py` بعد ضبط السر في بيئة آمنة، و`BIGBEN_AUDIT_BASE_URL` عند الحاجة. لا تمرر السر في الرابط أو سطر أوامر ظاهر. هذا فحص API/State مصرح به؛ لا يُسمى اختباراً بصرياً لجلسة المستخدم. يبقى فحص الواجهة الخاصة عبر Basic Auth الأصلي، وفحص HTML المصوّر في CI منفصلاً.

## اختبار النقل الاصطناعي المعزول
`POST /v1/tradingview/transport-test` مع رأس `X-BigBen-Test-Token` مستقل، و`BIGBEN_TRANSPORT_TEST_ENABLED=1`، ومعرف اختبار مطابق تماماً لـ`BIGBEN_TRANSPORT_SELF_TEST_ID`.

يختبر سيناريو سوق مغلق يمنع الإرسال، ثم إرسال بطاقة شراء اصطناعية وتحليل اصطناعي مستقل إلى أول مستخدم Telegram مصرح، ثم إعادة الطلب للتحقق من منع التكرار. كل رسالة موسومة بوضوح بأنها أسعار مصطنعة وليست توصية. القوالب لا تدخل جدول الأحداث أو سجل الصفقات الحقيقي. تحفظ المنصة معرفي الرسالتين اللذين أعادهما Telegram ولا تعيد الإرسال عند نتيجة غير مؤكدة.

يمكن للخادم تنفيذ الاختبار عبر HTTP المحلي عند الإقلاع بالمعرف المحدد نفسه. يعطّل اختبار النقل ويُفرّغ معرف التشغيل بعد الحصول على الإثبات، وتبقى إيصالاته محفوظة. هذا يثبت قبول Telegram والنقل المعزول والتحقق ومنع التكرار، ولا يثبت منشأ TradingView أو تغذية السوق الحية أو نجاح صفقة. إثبات التنبيه الحقيقي يتطلب تفعيل Webhook ثم مقارنة سجل TradingView ومعرف الحدث وإيصال المنصة وTelegram عند حدوث إشارة فعلية.

الأخبار لا تدخل بطاقة الصفقة أو التحليل أو متابعة TP/SL؛ أخبار اليوم وتنبيهاتها واختبار سيناريوهاتها في رسائل مستقلة. الفلتر الداخلي يستطيع حجب الدخول بسبب خبر دون حقن تفاصيل الخبر في البطاقة.
