# سجل التنفيذ
## مكتمل محليًا
- استعادة 38 ملفًا من النسخة الأساسية وحفظ تاريخ Git الأصلي.
- فرع تطوير مستقل؛ لا تغيير على Pine ولا main حتى هذه النقطة.
- إصلاح إغلاق SQLite وإضافة ترحيل received_at وفهارس دون حذف بيانات؛ الوقت القديم غير المعروف يبقى NULL.
- تقوية مقارنة التوكنات مع Unicode.
- API تحليل خاص يصف أدلة Heartbeat ويفصل الوقتين ويمنع ادعاء توقع أو ربحية.
- قسم أهداف السكالب: الصفقة الأصلية وخيار حسابي 1R، ترشيح رمز واتجاه وRR، حداثة، مراقبة إغلاقات، وأثر التيك إذا ورد.
- تنبيه Telegram واحد يجمع كامل الصفقة والسكالب.
- دعم اسمي TWELVE_DATA_API_KEY وTWELVEDATA_API_KEY.
- رفض تاريخ غير مرتب أو مكرر أو غير مكتمل أو غير صالح، وتقرير فجوات بلا اختلاق شموع.
- تحضير CI لـ Windows وLinux وترحيل PostgreSQL معزول.
## التحقق
51 اختبار خلفية ناجح قبل هذا السجل، يتضمن 11 اختبار سكالب واختبارات HTTP فعلية.
15 اختبار بحث وجودة بيانات نجحت في جلسة التطوير السابقة قبل آخر تغييرات السكالب؛ يجب تشغيلها في CI على commit النهائي.
فحص صياغة JavaScript المحلي نجح: 6 كتل inline، بعد إصلاح ترميز UTF-8 للفحص على Windows.
## الخطوة التالية
رفع الحزمة إلى فرع التطوير، إنشاء PR، انتظار فحوص CI، ثم نشر النسخة المجازة وفق تفويض المالك وفحص الصحة.
