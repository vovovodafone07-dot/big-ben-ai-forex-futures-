# التشغيل
ابدأ بفحص /healthz ثم /healthz/storage و/healthz/integrations. configuration_only لا يعني وصول بيانات حية.
ادخل اللوحة عبر HTTPS بمستخدم bigben وكلمة السر المحفوظة خارج المستودع.
افتح #scalping لرؤية الهدفين، #analysis للأدلة المرصودة و#settings لتشخيص الاتصال.
إذا لم تظهر إشارات: تحقق من وقت المصدر والرمز وAny alert() function call والتوكن وحالة التخزين، دون طباعة الأسرار.
إذا كانت قديمة: تحقق من السوق والجلسة والتنبيه؛ لا تستنتج انقطاع المنصة أو إغلاق السوق تلقائيًا.
إذا فشل Telegram: راجع acknowledgment والمحادثة المسموح بها؛ لا تعد إرسال الصفقة يدويًا دون مراعاة التكرار.
قبل انتهاء PostgreSQL المجاني في 11 ديسمبر 2026، جهز نسخًا احتياطية ومسار استمرارية بموافقة التكلفة.
