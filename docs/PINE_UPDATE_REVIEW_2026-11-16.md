# مراجعة تحديث Pine — 16 نوفمبر 2026

## الحالة الحالية

تمت مراجعة `tradingview/Big_Ben_AI_Pro_Multiasset_M5_v6_4_3.pine` قراءة فقط. النسخة الحالية تحتوي على:

- Breakout + Retest أو Confirmed breakout.
- اتجاه M15/H1/H4 باستخدام شموع أعلى إطار مغلقة.
- BOS وFVG وLiquidity Sweep وTurtle Soup وCRT وCISD وQM كأدلة/مرشحات.
- SMT اختياري مع رمز مقارنة يختاره المستخدم.
- حد أدنى للأدلة، حد أقصى لمسافة الوقف مقابل ATR، cooldown، ومنع الإشارة أثناء وجود حالة صفقة داخلية.
- صناديق المخاطرة والعائد وخطوط Entry/SL/TP.
- لوحة MTF مختصرة وعلامات BUY/SELL.
- Webhook JSON وHEARTBEAT على شموع M5 المغلقة، دون أوامر وساطة.

لم يتم تعديل أي ملف Pine أو إعداد TradingView أو Alert.

## الملاحظات المحافظة

1. اللوحة الحالية تعرض اتجاهات MTF وحالة عامة، لكنها لا تعرض بوضوح سبب الإشارة، عدد الأدلة، عمر آخر نبضة، أو سبب WAIT.
2. نص الملصق يعرض Entry/SL/TP وRR وEvidence، لكن لا توجد حالة مرئية موحدة للبيانات القديمة أو انتهاء صلاحية السيناريو.
3. يوجد فرق بين نسخة `bigben_tradingview.pine` المختصرة ونسخة `v6.4.3` متعددة الأصول. لا أوصي بتعديل النسخة المختصرة أو استبدال المصدر الحي بها.
4. تعليق النسخة الحالية ما زال يذكر عنوان Render القديم؛ هذا تعديل توثيقي لا يتطلب تغيير قواعد التحليل، وقد تم تحديث مرجع المستودع فقط في فرع التحويل غير المنشور بسبب تعذر صلاحية push.
5. نجاح Webhook لا يثبت ربحية أو تطابقاً تاريخياً مع Pine. لا يجوز إضافة أرقام أداء أو تحويل Evidence إلى احتمال نجاح.

## المقترح الذي ينتظر موافقة المالك

### تحديث العرض فقط — الخيار الموصى به

- لوحة حالة موسعة: `Decision`, `Evidence x/8`, `Trigger`, `M5 closed candle`, `Signal age`, `Invalidation`.
- تقسيم بصري واضح بين `Entry`, `SL`, `TP`، مع تلوين ثابت للشراء والبيع.
- إظهار `WAIT`, `STALE`, أو `INSUFFICIENT_DATA` بدلاً من ترك المستخدم يستنتج الحالة من غياب العلامة.
- إضافة ملصق مصدر: `READ-ONLY · No broker orders`.
- إبقاء كل إعدادات الدخول الافتراضية وقواعد الإشارة كما هي.
- إبقاء JSON وHEARTBEAT وalertcondition كما هي، مع تحديث عنوان Webhook فقط في نسخة معتمدة بعد موافقة منفصلة إذا لزم.

### تحسينات تحليلية اختيارية — لا تُنفذ الآن

- إضافة سبب رفض منظم لكل شرط دون تحويله إلى إشارة.
- إظهار حالة SMT/CISD/FVG/Sweep كـ`TRUE/FALSE/UNKNOWN` مع احترام تأخر pivot.
- إضافة فلتر جلسة اختياري مع `America/New_York`، مغلق افتراضياً.
- إضافة فلتر ATR/4H اختياري، مغلق افتراضياً.
- اختبار كل فلتر منفرداً على baseline، ثم مقارنة عدد الإشارات وMax Drawdown وExpectancy بوحدة R؛ لا يُعتمد أي فلتر قبل نتائج مستقلة.

## قرار التنفيذ

لا يوجد تنفيذ قبل موافقة صريحة على أحد الخيارين:

- `العرض فقط`: تحديث اللوحة والملصقات والحالات دون تغيير شروط الإشارة.
- `العرض + التحليل الاختياري`: إضافة تشخيصات/فلاتر اختيارية مع خطة اختبار منفصلة، دون تفعيلها افتراضياً.
