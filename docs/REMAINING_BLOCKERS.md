# العوائق المتبقية
1. Twelve Data: المالك وافق على استخدام مفتاح حسابه الحالي داخل Render دون شراء أو زيادة تكلفة. يلزم وصول مدعوم للحساب أو إدخال المفتاح في أسرار الخدمة. لا تطلب المفتاح في المحادثة.
2. TradingView: فشل التحكم بالمتصفح سابقًا لأن أداة Windows لم تتحقق من URL. لا تجتز القيد ولا تغيّر التنبيهات عشوائيًا. المطلوب فحص Any alert() function call ووصول حدث حي معروف، مع إبقاء الاستراتيجية.
3. صلاحيات الفيوتشرز: وجود حساب لا يثبت تغطية NQ/MNQ/ES/MES/YM/6E أو M5؛ يجب اختبار كل رمز وعقد مرخص.
4. لا أصل فيديو متاح ضمن الملفات؛ لا يمكن إثبات مطابقة المرجع بالباك تيست الحالي.
5. PostgreSQL المجاني مسجل بانتهاء 11 ديسمبر 2026. لا تنشئ خطة مدفوعة دون سقف تكلفة معتمد.
6. التسليم الحي لـ Telegram، تنفيذ schedule، مطابقة Pine بارًا ببار، التكاليف وwalk-forward والاختبار المستقل ما زالت غير مثبتة.
7. نظام الوكلاء التسعة، جميع كيانات البحث، ودورة الموافقات في Strategy Lab غير مكتملة.

## تحديث الاعتماد
كشف فحص الإنتاج بعد PR #4 أن مفتاح Twelve Data مضبوط بالفعل. استخدامه الحالي مصرح من المالك. أضيف اختبار خادمي محدود؛ ما زال يلزم انتظار نتيجته، ثم إثبات صلاحيات كل رمز. لا تغيّر السر أو تنشئ مفتاحًا جديدًا دون حاجة.
