# العمل المتبقي وحدود التحقق

## ما تم حسمه
- الرموز التسعة مرتبطة فعليًا عبر TradingView M5/v6.4.1؛ وصلت دورة19:15 UTC كاملة وقبلها الخادم202 دون تكرار. لا حاجة لإعادة إنشاء هذه التنبيهات.
- الفوركس التاريخي يعمل بالمفتاح الحالي:2997 شمعة مغلقة. الأدوار التسعة نفذت27 مهمة وحفظت3 تقارير.
- قبل Telegram رسالة اختبار حقيقية؛ لا تطلب المفتاح الحالي ولا تعيد اختبار الرسائل دون سبب.

## المتبقي
- انتظار إشارة BUY/SELL سوقية حقيقية للتحقق من رسالة الصفقة الكاملة والسكالب؛ لا تُنشئ صفقة زائفة في الإنتاج. لم يثبت استقبال الهاتف/قراءة المستخدم.
- تاريخ فيوتشرز مرخص مستقل، بيانات العقود والتدوير والتقويم وتغطية كل رمز لدى مزود API غير مهيأة. نبضات العقود تعمل، ولا تعوض التاريخ الكامل أو تثبت ترخيص API.
- الباك تيست الحالي proxy RR3 وليس Pine RR2.5. مطابقة قواعد Pine بارًا ببار، تكاليف التنفيذ، walk-forward وholdout واسع مستقل متبقية. الأصل المرجعي بالفيديو غير متاح للتحقق الدقيق؛ لا تستبدل الاستراتيجية تلقائيًا.
- نظام المرشحين واعتمادهم الدائم وملاحظات المستخدم وسجلات البحث الشاملة وأخبار/تقويم API والتحليل الهجين المستقل غير مكتملة.
- الجدولة على Render الحالي best effort أثناء تشغيل الخدمة؛ أول تنفيذ مثبت، مرور دورة مؤقت كاملة لم يُختبر. GitHub workflow القديم الخاص بـBarchart منفصل وما زال يحتاج إعداد مصدره. لا تنسب له تقارير Render الجديدة.
- قيد TradingView يمنع تضمين بعض العقود في الودجت خارج الموقع. عرض Forex وروابط العقود هو المسار المدعوم؛ لا تتجاوز القيد.
- تحديث صفحة التحليل (الحديث أولًا، قيم الفريمات ونسخة المصدر، Forex افتراضيًا) قيد الاختبار والنشر.

## الصيانة
- PostgreSQL المجاني ينتهي11 ديسمبر2026؛ لا ترفع التكلفة دون سقف معتمد. لا تفتح IP allowlist الخارجية؛ التطبيق يعمل داخليًا.
- راقب تواريخ انتهاء التنبيهات؛ تاريخ MES المرصود9 ديسمبر2026. تنبيها الذهب بقيَا على لقطتهما الأصلية.
- الاعتمادات في أسرار Render فقط؛ لا تطبع مفاتيح أو رسائل مزود خام أو توكن Webhook.
