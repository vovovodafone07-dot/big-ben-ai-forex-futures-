# التراجع
احتفظ بالنسخة الأساسية f64490ca543d6576efb27420987383726a7136eb ومعرف آخر deploy حي قبل النشر.
لتعطيل عرض السكالب يمكن الرجوع إلى إصدار الواجهة السابق؛ Pine لم يتغير.
الهجرة إضافية: received_at وفهارس وسجل إصدارات. لا تحذف العمود أو السجلات عند التراجع.
كود النسخة الأساسية يستخدم INSERT OR IGNORE INTO events VALUES بخمس قيم في SQLite؛ بعد إضافة العمود يجب استخدام إدخال بأسماء الأعمدة عند التراجع إلى SQLite. PostgreSQL الأساسي يستخدم أسماء الأعمدة ويظل متوافقًا.
تراجع Render لا يعكس بيانات DB أو الرسائل المرسلة. افحص التوافق وحالة autoDeploy والصحة بعده.
