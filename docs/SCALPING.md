# الصفقة الكاملة وخيار السكالب
GET /api/scalping?rr=1 محمي بمصادقة لوحة المنصة. RR بين 0.5 و3، والهدف يُحد عند الهدف الأصلي.
كل بطاقة تبقي Entry/SL/TP/RR الأصلي وتعرض بديلًا حسابيًا بنفس Entry وSL. ليست إشارة جديدة ولا تعديلًا لاستراتيجية Pine.
الافتراضي 1R. اختيار RR في الواجهة يغير العرض فقط؛ Telegram يعرض 1R في الرسالة نفسها بجانب الهدف الأصلي.
لا يكرر الإرسال للحدث نفسه. Heartbeat لا يرسل رسالة صفقة.
يعرض آخر BUY/SELL لكل رمز فقط خلال 12 دقيقة، ويستبعد الإشارة المستقبلية والبيانات غير الصالحة. هذه نافذة عرض، وليست مدة صلاحية مثبتة.
إغلاق لاحق بعد الوقف أو الهدف الأصلي يستبعد البطاقة. إغلاق بعد هدف السكالب يوسم كرصد وصول، ولا يثبت تنفيذ صفقة أو ترتيب لمس المستويات داخل الشمعة.
إذا ورد tick_size يقرب الهدف باتجاه الدخول. بدونها يصرح بأن التيك غير متحقق؛ لم تُخمن مواصفات العقود.
السبريد والعمولة والانزلاق غير محسوبة. فتح الخيارين معًا يضاعف التعرض؛ الواجهة والرسالة توضحان ذلك.
