# الأمان
احتفظ بالأسرار داخل Render Environment وGitHub Actions Secrets. .env.example يحوي أسماء بلا قيم.
توكن الويبهوك لا يُخزن في payload. received_at يأتي من الخادم لا من العميل.
GET /api/analysis و/api/scalping محميان بنفس مصادقة اللوحة، ولا تكشف فحوص الصحة قيم الأسرار.
قاعدة PostgreSQL لا تسمح باتصالات خارجية في آخر فحص؛ لم يُفتح allowlist.
لا تداول، لا اتصال وسيط، لا نشر Pine تلقائي، ولا تعديل استراتيجي إنتاجي.
متبقٍ: طابور إشعارات دائم، حدود معدل أوسع، حماية تشغيلة الخادم وتحديد retention للبيانات.
