# البوت التفاعلي ومحرك التحقق الهيكلي

## ما يطبقه الكود
- أزرار عربية للسكالب والسوينغ والأصول الموثقة والأخبار وحالة السوق والمتابعة وتحديث التحليل.
- التفاعل محصور بمحادثات خاصة ومعرّفات مستخدمين مصرح بها. عضوية مجموعة لا تمنح صلاحية تلقائية.
- استقبال تحديثات Telegram على `/v1/telegram/updates` بسر مستقل في رأس `X-Telegram-Bot-Api-Secret-Token`. لا يستخدم مسار TradingView أو سره.
- حفظ رقم كل تحديث قبل معالجته لمنع إعادته بعد إعادة التشغيل. الإرسال غير المؤكد يحتاج مراجعة؛ لا يمكن ضمان التسليم مرة واحدة في Telegram.
- نشرة يومية واحدة لكل وجهة، الساعة 07:00 بتوقيت عُمان افتراضياً. التنبيهات الشخصية اختيارية. سيناريو الخبر تعليمي ولا يولد صفقة أو يختلق التوقع أو السابق.
- المراقب داخل خدمة Render المجانية؛ عند نوم الخدمة أو توقفها قد تتأخر النشرة حتى الاستئناف. لا يوجد ضمان زمني لخادم مجاني نائم.
- تقويم BLS المتاح لا يغطي وحده جميع أحداث العالم أو كل اجتماعات الفائدة، ولا يوفر أرقام التوقعات. تُعرض القيم غير المتوفرة صراحة.

## التهيئة المطلوبة قبل التشغيل الفعلي
1. استخدم البوت الحالي؛ لا تنشئ بوتاً أو خدمة مدفوعة جديدة.
2. أضف إلى إعدادات الخادم `BIGBEN_TELEGRAM_ALLOWED_USER_IDS` كقائمة معرّفات المستخدمين الرقمية المصرح بها، وليس أسماء الحسابات أو معرّف مجموعة.
3. ضع `BIGBEN_TELEGRAM_WEBHOOK_SECRET` في مخزن أسرار الخادم بقيمة عشوائية مستقلة لا تقل عن 32 محرفاً. لا تضعها في Git أو الرسائل أو عنوان الرابط.
4. افحص `getWebhookInfo` للبوت الحالي أولاً. لا تستبدل Webhook آخر مستخدم قبل تحديد وظيفته والمحافظة عليه.
5. سجل `setWebhook` لعنوان HTTPS الخاص بالمنصة مع `/v1/telegram/updates`، ومرر السر في `secret_token`، و`allowed_updates` بالقيم `message` و`callback_query`، واحتفظ بالتحديثات القديمة (`drop_pending_updates=false`). لا ترسل التوكن إلى أي خدمة أخرى.
6. ابدأ محادثة خاصة مع البوت وأرسل `/start` ثم اختبر الأزرار دون إرسال صفقة اصطناعية. نجاح نشر الكود لا يعني أن هذه الخطوات نُفذت.
7. موعد النشرة قابل للتعديل عبر `BIGBEN_NEWS_DIGEST_HOUR` بين 0 و23 بتوقيت عُمان.

## فلتر الدخول
السكالب يستخدم تنفيذ M5 والسوينغ H1، مع سياق H1/H4. تأكيد الإعداد يتطلب اتجاهًا متوافقًا ونطاق حركة كافيًا، وسحب سيولة سابقًا، ثم كسر هيكل بزخم وتكوّن FVG، ثم إعادة اختبار مغلقة تحفظ المنطقة. الوقف خلف أقصى منطقة الإبطال مع هامش لا يقل عن حركتين سعريتين وربع ATR لفريم التنفيذ. القواعد تعريف عملي محدد وليست ادعاءً بتطبيق كل مدارس SMC/ICT أو كشف CISD وIFVG وOrder Block كاملة.

لم يُثبت انخفاض نسبة ضرب الوقف؛ يلزم اختبار تاريخي خارج العينة وبنفس المصدر مع التكاليف. ملفات Pine والتنبيهات القائمة لا تتغير. لا يوجد تنفيذ أوامر وسيط.
